# DESIGN.md - デザインガイドライン

株式会社クリエイターのうえきばち コーポレートサイト（creatorpot.net）のデザインの決まりごと。
**2026-10 に明るい配色へ作り直した**（経営ポータルの決定 0087）。それ以前の「ダークファースト」の版は git の履歴にある。

`/business-game/` は独自の Grid テーマ（ページ内の `.lp` の変数。正は `lp-design.pen` の `gd-*`）を持つので、この文書の対象外。

---

## 1. 原則

1. **読み手の判断のために置く。** サイトに来るのは、代表からの連絡や紹介で社名を知り、「この会社に何を・いくらくらいで・どう頼めるか」を確かめに来た企業の担当者が多い。要素ごとに「どの読み手の、どの判断のためか」を言えること。言えない要素は置かない。
2. **意図のない飾りを置かない。** 理由なく3つを横に並べたカード、意味のない SVG アイコン、光彩・グラデーション、絵文字、バッジの乱発はしない。比べて読むものは表か行の一覧にする。
3. **世界観は本物の制作物で出す。** 所属クリエイターの絵、NoLogic の画面、メンバーの顔写真。ストック写真や飾りの図形で雰囲気を作らない。
4. **読みやすさと会社としての落ち着きを優先する。** 明るい紙色の背景に墨色の文字。本文は16px以上、行間1.85前後、1行は全角40字程度まで。
5. **主ボタンは1画面に1つ。** 2番手の行動は線のボタンか文字のリンクにする。

## 2. 色

変数の正は `src/styles/site.css` の `:root`。Tailwind からは `text-[var(--muted)]` のように使う。暗い色の直書き（`bg-[#0A0F1C]` `text-white` など）は使わない。

| 変数 | 値 | 用途 |
|---|---|---|
| `--paper` | `#f7f9f8` | 背景 |
| `--paper-2` | `#edf2ef` | 交互の帯（`.band--alt`）、フッター下段 |
| `--card` | `#ffffff` | 画像の台、入力欄 |
| `--ink` | `#13201c` | 見出し・本文の強い文字、区切りの太線 |
| `--ink-2` | `#2c3a35` | 本文 |
| `--muted` | `#4e5d57` | 補足（`--paper` 上で約6.6:1） |
| `--rule` / `--rule-strong` | `#d5ddd9` / `#9aa8a2` | 罫線 |
| `--accent` | `#10b981` | ブランド色（エメラルド）。**線・印・面だけ**に使う。文字には使わない（`--paper` 上で約2.4:1） |
| `--accent-ink` | `#047857` | 文字のリンク、主ボタンの背景（白文字と約5.5:1） |
| `--accent-ink-hover` | `#065f46` | 主ボタン・リンクのホバー |
| `--accent-wash` | `#e3f4ec` | 選択状態などの薄い面 |

ブランド色の正は経営ポータルの `slide-kit/design/スライドデザイン規約.md`（ティール #26afa7）。サイトはエメラルドを使い続ける（決定 0087 で pending-0040 を閉じた）。

## 3. 文字

- 書体は Zen Kaku Gothic New（400・700・900。`Layout.astro` で読み込む）。エッセイの本文だけ BIZ UDPMincho。
- 級数は変数（`--t-h1` `--t-h2` `--t-h3` `--t-lead` `--t-body` `--t-sm` `--t-xs`）とクラス（`.h1 .h2 .h3 .lead .body .small .kicker`）で指定する。
- 数字を並べるところは `.num`（等幅数字）。日付や短い括弧書きは `.nb` で行末で割らない。
- 節の見出しの上には `.kicker`（何の節かを先に知らせる短い日本語のラベル）。英字の大文字ラベル（SERVICES など）は使わない。

## 4. 骨組み

- 横幅は `.shell`（本文の最大幅1180px＋左右の余白）。節は `.band`（上下72〜96px）と `.band-lg`。交互の帯は `.band--alt`。
- 一覧の始まりは2pxの墨色の線（`.rule-ink` または同じ指定）、行の区切りは1pxの `--rule`。
- 2カラムにするときは12分割のグリッド（`lg:grid-cols-12`）で、見出しを左に4〜5、本文を右に7〜8。

## 5. 部品

| 部品 | クラス・ファイル | 決まり |
|---|---|---|
| 主ボタン | `.btn`（`.btn--sm`） | 高さ52px（小は44px）、角丸8px、`--accent-ink`。1画面に1つ |
| 線のボタン | `.btn-line` | 2番手の行動（日程調整など） |
| 文字のリンク | `.link` | 下線つき。本文中の移動はこれ |
| 表 | `.table-plain` | 会社概要・料金など、比べて読むもの |
| ヘッダー | `src/components/Navigation.astro` | 高さ68pxの固定。props `contactHref` `current` |
| フッター | `src/components/Footer.astro` | 上段に相談の案内（主ボタン・日程調整・メール）。フォームを持つページは `hideCta` |
| 問い合わせフォーム | `src/components/ContactForm.tsx` | 種別・送信元ページを Supabase に残す。props `defaultCategory` |

フォーカスは3pxの `--accent` の外枠で示す（`.btn` `.btn-line` `.link` に指定済み）。タップ領域は44px以上。

## 6. 動き

- スクロールに合わせて要素を出す演出は使わない（読ませるページなので）。
- 動画は音なし・繰り返しで、画面に入ったときだけ再生する。`prefers-reduced-motion: reduce` のときは再生しない。
- ホバーの変化は色だけ（0.15秒）。

## 7. 計測（GA4）

| 属性 | 送るイベント | 置く場所 |
|---|---|---|
| `data-cta-location="..."` | `cta_click`（`cta_location`, `page_path`） | 相談のボタン・用件の入口 |
| `data-schedule-location="..."` | `schedule_click`（`cta_location`, `lp_id`, `page_path`） | 日程調整のリンク |
| `data-section="..."` | `section_impression`（受託のページ） | 各節 |

クリックの送信は `Layout.astro` の共通スクリプトが行う。ページ側で同じイベントを重ねて送らない。フォームの `generate_lead` は `ContactForm.tsx` が送る。

## 8. 画像

- 写真・絵は Astro の `Image`、または `width` `height` `loading="lazy"` を付けた `<img>`。
- `src/assets/hero-bg.png`（ゲーム機材のストック写真）は使わない。
- 絵や画面には、何の絵・何の画面かが分かる説明（`figcaption`）を添える。
