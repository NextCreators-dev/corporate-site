## 2. 課題

### 見出し
伝えたつもりで、届いていない。

### 本文
入社した週に配った会社案内を、半年後まで覚えている人はほとんどいない。

ミッション・ビジョン・バリューを壁に貼った。でも日々の判断の場面で、誰もそれを持ち出さない。

部署をまたぐと名前しか知らない。交流施策は初回は盛り上がり、2回目はたいてい続かない。

説明会で事業を丁寧に説明した。それでも入社後に「思っていたのと違う」と言われる。

### 小見出し
なぜゲームか

### 本文
読むだけの情報は流れていきますが、自分で選び、操作し、結果を見た体験は残ります。隣の人と一緒に遊べば、そこに会話が生まれます。部署が違う人同士なら、なおさらです。

ただ、ゲームは作ればいいわけではありません。何を作るかを決め、権利を整理し、社内で実際に遊ばれる状態まで運んで、はじめて効果が出ます。制作ツールや生成AIでゲームを「作ること」自体は簡単になりました。私たちが引き受けるのは、その前と後です。

## 3. こんな場面で

### 見出し
こんな場面で

### 新入社員研修・オンボーディング
会社の歴史、事業内容、行動指針をクイズ形式やノベル形式に。配属前に会社の全体像が頭に入った状態をつくります。

自己紹介ゲームや部署対抗のミニゲームで、雑談のきっかけをつくります。全社イベント、懇親会、リモート環境での交流に。

### 説明会・インターンでの二次利用
新入社員研修用に作った会社理解のゲームは、そのまま学生にも見せられます。事業や行動指針を入社前に体験してもらうことで、入社後の「思っていたのと違う」を減らします。

## 4. 私たちだからできる理由（新設）

### 見出し
私たちだからできる理由

### 特徴1
**短納期・低コスト。**
テンプレート型のゲーム制作基盤NoLogicで、累計600本以上のゲームが作られています。この基盤とAIコーディング支援を使い、企画から試作版まで最短1週間。小さく試して、効果を見てから広げられます。

### 特徴2
**素材は自社クリエイターのオリジナル。**
キャラクター、イラスト、楽曲は所属クリエイターが制作します。研修や社内利用の際の権利関係が明確で、貴社のブランドガイドラインに合わせた調整にも応じます。生成AIは工程で使い、品質と権利の最終確認は人が行います。納品後の動作保証と保守も自社で担います。

### 特徴3
**遊ばれる状態まで設計し、結果を数字で返す。**
2,800人規模の高専コミュニティと、自社クリエイターコミュニティNextCreatorsの運営で、参加者が自発的に盛り上がる仕組みづくりを続けてきました。ゲームだけでなく、社内での展開方法と導入後の運営まで提案します。納品後は、プレイ完了率や設問ごとの正答率をレポートとしてお渡しします。どこで理解が止まっているかが分かるので、次の研修の設計にも使えます。
